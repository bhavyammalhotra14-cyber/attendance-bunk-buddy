# Attendance Bunk Buddy

Attendance & Bunk Calculator
College students constantly ask “how many classes can I skip and still stay above 75%?” Build a per-subject tracker where they log present/absent days and see the safe-bunk count, required attendance, and a color-coded risk status. Make it just a front end based project and include some sample database to refer to.
